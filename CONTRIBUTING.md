# Contributing to Sortiva

First off, thank you for considering contributing to Sortiva! It's people like you that make Sortiva such a great tool.

## How Can I Contribute?

### Reporting Bugs
- Use the [Bug Report Template](https://github.com/rahulroynipon/sortiva/issues/new?template=bug_report.md) to report bugs.
- Provide a clear and descriptive title.
- Describe the exact steps which reproduce the problem.

### Suggesting Enhancements
- Use the [Feature Request Template](https://github.com/rahulroynipon/sortiva/issues/new?template=feature_request.md) to suggest enhancements.
- Explain why this enhancement would be useful to most Sortiva users.

### Pull Requests
- Fill out the [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md) when opening a PR.
- Ensure your code follows the existing style of the project.
- Make sure all tests pass before submitting.
- Link the PR to a related issue if possible.

## Technical Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rahulroynipon/sortiva.git
   cd sortiva
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development environment:**
   ```bash
   npm run dev
   ```

4. **Run the demo project:**
   ```bash
   cd demo
   npm install
   npm run dev
   ```

5. **Running Tests:**
   ```bash
   npm test
   ```

## Code of Conduct
Please be respectful and professional in all your interactions with the project and its contributors.
